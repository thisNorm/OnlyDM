# OnlyDM for Ubuntu

Ubuntu 24.04 x64용 시험판입니다. 같은 저장소의 Windows판은 기존 방식으로 빌드합니다.

공식 Instagram 웹 화면에서 로그인하면 OnlyDM의 채팅 목록을 볼 수 있습니다. 방을 두 번 클릭하거나 선택하고 Enter를 누르면 대화가 열립니다. 상단 뒤로 버튼이나 Esc로 목록에 돌아갑니다. 방을 닫으면 입력 중이던 내용은 유지되지 않습니다.

시험판은 대화 목록과 검색, 기존 대화에서 메시지 읽기와 보내기, 계정 전환, DM 알림을 지원합니다. 친구 목록, 새 채팅, 음성·영상 통화, 트레이는 포함되지 않습니다.

## 계정 전환과 DM 알림

대화 목록 위의 **계정 전환** 메뉴에서 **계정 추가…**를 고르면 별도 Chromium 프로필에 Instagram 공식 로그인 화면이 열립니다. 새 프로필마다 처음 한 번 직접 로그인하면, 로그인 상태가 유지되는 동안 메뉴에서 바로 전환할 수 있습니다. Windows나 휴대폰의 로그인 상태는 가져오지 않습니다. 연결된 프로필은 **Instagram 프로필 선택…**에서 공식 계정 선택 화면을 열어 고를 수 있습니다.

OnlyDM이 실행 중이고 각 계정의 브라우저 세션에 로그인되어 있으면, 현재 보지 않는 계정의 새 DM도 데스크톱 알림으로 뜹니다. 알림에 수신 계정이 표시되고, 누르면 해당 계정의 대화 목록으로 전환됩니다. 알림에는 메시지 본문이 표시되지 않으며, 미리보기 옵션은 없습니다. 알림을 받으려면 Ubuntu의 데스크톱 알림 서비스가 실행 중이어야 합니다.

백그라운드에서는 계정별 받은편지함만 확인하며 채팅방 탭은 열지 않습니다. 일시적인 오류가 나면 앱이 실행 중인 동안 5초 → 30초 → 60초 → 2분 간격으로 다시 시도합니다. 이후에는 2분마다 횟수 제한 없이 시도합니다. Instagram이 다시 인증을 요구하면 해당 계정의 확인을 멈추고, 앱을 종료하면 모든 확인이 끝납니다.

## 설치

[GitHub 릴리스 v1.1.0](https://github.com/thisNorm/OnlyDM/releases/tag/v1.1.0) 기준입니다. Ubuntu 데스크톱에서 `OnlyDM-linux-x64.deb`를 내려받은 폴더를 열고 다음 명령을 실행합니다.

```sh
sudo apt install ./OnlyDM-linux-x64.deb
```

앱 목록에서 **OnlyDM**을 실행합니다.

## 소스에서 빌드

Ubuntu 24.04 x86-64, Node.js 22.12 이상, .NET 8 SDK, `dpkg-deb`가 필요합니다. Electron은 Linux 빌드 과정에서 받습니다. 실행할 PC에는 Node.js와 .NET SDK가 필요하지 않습니다.

```sh
cd linux
npm ci
npm run build
npm test
npm run package:deb
```

소스 빌드의 설치 파일은 `dist/onlydm_0.1.0~beta.4_amd64.deb`에 생성됩니다. 데스크톱 세션에서 `npm start`로 개발용 앱을 실행할 수 있습니다. `npm run test:ui`는 별도 테스트 프로필과 가짜 Instagram 페이지에서 로그인 후 목록, 방 열기, 메시지 입력 및 전송, 목록 복귀와 계정별 로그인 상태를 검증합니다.
